# Сопоставление отправителей и получателей открыток

- Программа обрабатывает корпус открыток в формате .xlsx и строит две таблицы соответствий: отправитель → все его получатели с количеством открыток, и получатель → все его отправители.

## Пошаговая инструкция по установке и запуску
**Шаг 1. Установка необходимого ПО.**
Этот шаг необходим *только* если на вашем устройстве отсутствует среда разработки, поддерживающая Python версии 3.10 или выше. В иному случае переходите к Шагу 2.
1. Установите любую среду разработки (например, Visual Studio Code).
2. Проверьте, установлен ли в этой среде разработки Python версии 3.10 или выше; если да - переходите к Шагу 2.
3. Перейдите на официальный сайт: https://www.python.org/downloads/
4. В нижней части страницы кликните на установщик ("installer") для вашей операционной системы (для большинства это будет "Windows installer (64-bit)") и выберете, куда скачать файл
5. Запустите скачанный установщик.
6. **Важно:** на первом экране установки поставьте галочку "Add python.exe to PATH" внизу окна — без этого шага программа не будет запускаться из командной строки. Это единственный нестандартный момент во всей установке.
7. Нажмите "Install Now" и дождитесь завершения.

**Шаг 2. Скачивание данных репозитория.**
1. Перейдите по ссылке на репозиторий проекта: 
2. Кликните на кнопку `Code` в правом верхнем углу страницы, над списком файлов
3. В выпадающем меню кликните на кнопку "Download ZIP" и выберите, куда скачать архив.
4. Распакуйте скачанный архив (правый клик по файлу → "Извлечь всё" в Windows, или двойной клик в macOS) и выберите, куда распаковать архив.

**Шаг 3. Установка зависимостей**
1. В вашей среде разработки откройте папку с данными репозитория (именно всю папку, не конкретный файл).
2. При необходимости изолировать зависимости от других программ (например, если вы разрабатываете другие программ) создайте venv (виртуальное окружение). Полное руководство по созданию venv вы можете найти [здесь](https://timeweb.cloud/tutorials/python/kak-sozdat-virtualnoe-okruzhenie).
3. В вашей среде разработки откройте терминал.
4. Для установки библиотеки `openpyxl` введите в терминале следующую команду и нажмите Enter:
```
pip install openpyxl
```
5. Дождитесь, пока в терминале появятся сообщения об успешной установке (обычно заканчивается строкой `Successfully installed openpyxl-...`).

**Шаг 4. Запуск программы.**
1. В уже открытом в Шаге 3 или новом терминале введите следующую программу и нажмите Enter, программа начнет выполнение:
```
python main.py
```
2. После начала выполнения в терминале появится сообщение:
```
Введите путь к файлу корпуса:
```
3. Откройте папку с файлом данных корпуса (файл обязательно должен иметь расширение .xlsx) и скопируйте путь к вашему файлу. В операционной системе Windows путь находится в верхней части окна проводника.
4. Вставьте скопированный путь в терминал, в конце добавьте название вашего файла с расширением. Строка должна выглядеть примерно так:
```
Введите путь к файлу корпуса: C:\Users\User\corpus.xlsx
```
5. Нажмите Enter. Вы увидите отчет по процессу выполнения в терминале. Программа завершит работу, когда в терминале появится следующая строчка:
```
Результат сохранен в файл "Сопоставление получателей и отправителей.xlsx". Спасибо за использование!
```
6. После этого можете закрыть среду разработки.

## Интерпретация результатов
### Столбец А
Содержит значения основных данных. На листе "Отправители - получатели" основные данные — имена отправителей, на листе "Получатели - отправители" — получатели. Ячейки объединены вертикально по количеству соответствующих связанных данных в столбце B.
### Столбец B
Содержит значения связанных данных. На листе "Отправители - получатели" связанные данные — имена получателей, на листе "Получатели - отправители" — отправители. Определяет объединение ячеек для стобца A.
### Столбец C
Содержит количество связей, найденных между основными и связанными данными в соответствующей строке
### Столбец E
Содержит количество тегов [ нрзб ] в основных данных. На листе "Отправители - получатели" основные данные — имена отправителей, на листе "Получатели - отправители" — получатели. **Важно:** данная строка считает только значения, полностью состоящие из данного тега.
- "[ нрзб ]" — считается ✅
- "Иван [ нрзб ]" — не считается ❌
### Столбец F
Содержит количество тегов [ отсутствует ] в основных данных. На листе "Отправители - получатели" основные данные — имена отправителей, на листе "Получатели - отправители" — получатели. **Важно:** данная строка считает только значения, полностью состоящие из данного тега.
- "[ отсутствует ]" — считается ✅
- "Иван [ отсутствует ]" — не считается ❌

## Известные ограничения
- Разные варианты написания одного и того же имени (например, "Иванов Пётр" и "Пётр Иванов") в результатах считаются разными людьми.
- Записи с несколькими именами в одной ячейке (например, "Сима, Миша") не разделяются на отдельных людей.
- Записи, помеченные как [ нрзб ] или [ отсутствует ], учитываются отдельно и не объединяются друг с другом.

## Возможные проблемы
| Проблема | Возможное решение |
| ----------- | ----------- |
| В терминале выводится подобная ошибка: `"python" не является внутренней или внешней командой`, `xcode-select: note: no developer tools were found`, `Command 'python' not found`.    | Python не установлен или IDE его не видит. Повторите шаги по установке Python из Шага 1 и удостоверьтесь, что поставили галочку "Add python.exe to PATH"   |
| В терминале выводится ошибка: `ModuleNotFoundError: No module named 'openpyxl'`    | Не установлена библиотека `openpyxl`, выполните Шаг 3.4.   |
| В терминале выводится ошибка: `TypeError: unsupported operand type(s) for \|: 'type' and NoneType.`    | Установлен Python версии ниже 3.10. Повторите шаги по установке Python из Шага 1 и убедитесь, что устанавливаете версию 3.10 или выше.   |
| Папка с проектом пустая.    | Вы просматриваете архивированную папку проекта. Откройте папку, в которой лежит архив, и распакуйте архив (правый клик по файлу → "Извлечь всё" в Windows, или двойной клик в macOS).   |
| В терминале выводится ошибка: `ОШИБКА: Путь к файлу отсутствует, инициация программы прервана`    | Путь к файлу не был введен. Повторите Шаг 4 и убедитесь, что ввели непустой путь к файлу.   |
| В терминале выводится ошибка: `ОШИБКА: Путь введен некоректно или файла не существует, инициация программы прервана.`    | Путь к файлу имеет некорректное оформление, ведет в несуществующую директорию или к несуществующему файлу. Проверьте правильность ввида пути, имени файла и расширения файла, введите путь повторно.   |
| В терминале выводится любая не упомянутая ранее ошибка, начинающаяся с `ОШИБКА: ...`    | Повреждена целостность файлов корпуса или программы. Удалите архивированную и распакованную папки программы, повторите Шаг 2 и проверьте целостность и корректность данных файла корпуса. Описание ошибки подскажет, на что обратить внимание.   |
| Программа зависла (долгое время не выводит данные о выполнении).    | Среда разработки не отвечает или обработка данных идет слишком долго. Перезапустите среду разработки (завершите процесс через диспетчер задач и откройте среду разработки снова). **Важно:** на больших объемах данных программа может выполняться долго, в среднем от нескольких минут до получаса. Не спешите прибегать к вышеупомянутым мерам.   |
| Не выходит найти файл с результатом.    | Файл с результатом автоматически сохраняется в папку программы (там же, где файлы main.py, postcards_lib.py и прочие).   |
| Файл с результатом не открывается.    | На вашем устройстве отсутствует средство просмотра файлов формата .xlsx. Установите любую программу для открытия файлов данного формата, например, LibreOffice. Полное руководство по установке LibreOffice вы можете найти [здесь](https://wiki.documentfoundation.org/Documentation/Install/Windows/ru).   |
